# Mining Systems Network & KPI Lab

A simulated operational-technology support project designed around the kind of work performed by mining-systems teams: network troubleshooting, OT/IT architecture, SQL-based KPI reporting, data validation, incident workflows, and technical documentation.

> **Important:** All IP addresses, device names, event records, KPIs, and performance data are simulated for educational and portfolio purposes. No confidential mine-site or vendor operational data is used.

## Project components

- **Network topology** for autonomous and conventional mining systems
- **Asset inventory** for field systems, workstations, VMs, servers, and enterprise tools
- **VLAN / IP plan** using private RFC1918 addressing
- **100 simulated operational events**
- **KPI dashboard** for incident severity, data completeness, MTTR, network reachability, and DNS success
- **ServiceNow-style incident workflow**
- **Troubleshooting runbook**
- **SQL queries** for operational KPI analysis

## Technologies and concepts demonstrated

- TCP/IP and IP addressing
- DHCP and DNS
- VLAN segmentation
- Active Directory / domain concepts
- Windows and Linux support concepts
- SQL and operational data analysis
- Data validation
- KPI reporting
- Incident triage and escalation
- ServiceNow workflow concepts
- Technical documentation
- OT / IT segmentation
- Root-cause analysis

## Simulated mining systems represented

The architecture includes portfolio-only representations of systems such as autonomous haulage, autonomous drilling, GNSS, collision avoidance, sensor analytics, OT workstations, virtual machines, DNS/DHCP, Active Directory, SQL, and incident-management services.

These names are included only to contextualize the lab against common mining-systems support workflows.

## Interview explanation

I built this project to practice the workflow of a mining-systems analyst rather than only reading about the technologies. I designed a simplified OT/IT network, created an IP and VLAN plan, built a simulated event dataset, and developed KPIs for system support. I also documented a repeatable incident workflow and troubleshooting runbook covering IP addressing, reachability, DNS, authentication, service health, SQL data freshness, and change review.

The project helped me connect my networking experience with the operational support requirements of industrial and mining environments.
